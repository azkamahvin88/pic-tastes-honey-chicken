One photorealistic close-up of honey-glazed fried chicken: still steaming,
shatter-crisp skin, glossy glaze dripping off the edge, against a dark
background. A single hero ingredient — honey — does all the talking, so the
picture itself tastes sweet, sticky, and savoury before a single bite.

## Program

`main.py` is Python 3.13, standard library only, no network. It copies
`entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when
that variable is set). The output is a PNG, 1024x683, 999,080 bytes — under
the 1 MiB / 1024x1024 limit.

## Run

```sh
python3 main.py
```
